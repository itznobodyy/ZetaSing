Step zero · required

DNS Profile

The ZetaSing profile configures the device DNS and also puts ZetaSing on your home screen with its icon, like an app. It is installed once.

Install ZetaSing profile

A .mobileconfig file signed with the ZetaSing name is generated. It holds the DNS setting and the shortcut with icon. After downloading, iOS will ask for confirmation in Settings.

InstallationWhat to do after downloading

Open it in Safari

The button must be pressed from Safari on the iPhone. The notice "This website is trying to download a configuration profile" will appear.

Allow the download

Tap Allow. The profile is downloaded, not installed yet.

Go to Settings

Settings → General → VPN & Device Management. You will see "ZetaSing DNS" under "Downloaded Profile".

Install it

Tap the profile → Install → passcode → Install → Install again.

Enable DNS

On the same screen open DNS and check the profile is active. If it does not show, restart the iPhone.

Check the icon

Installing the profile puts ZetaSing on your home screen with its emblem. Open it from there to browse full screen.

Important: if you remove the profile, signed apps stop connecting until you reinstall it. It does not need repeating between installs: it stays put.

Technical note: the profile resolves over encrypted DNS (DoH) via 1.1.1.1, which is what keeps company certificates alive when Apple blocks them on regular DNS. The shortcut is generated with this website address, so if you change domain, download it again.

Manual signing

Certificates .zip

Packages with .p12 and .mobileprovision to import inside ESign or KSign. Tap the password to copy it.

Careful: a package is for signing apps, not for installing the signer. For the signer use the ESign or KSign catalogs. The DNS profile is still required.

Before you startInstallation

Open in Safari

Everything is done in Safari on the iPhone. OTA links do not fire from Instagram, TikTok, Facebook or Chrome.

Install the ZetaSing profile

Go to DNS and follow the steps. It is required and done only once.

Pick a seal

Open ESign or KSign and tap "Install".

Confirm the dialog

iOS will show "Install?". Tap Install and wait for the icon to appear on the home screen.

Trust the profile

Settings → General → VPN & Device Management → tap the company → Trust.

Open the app

With DNS active and the profile trusted, the app opens normally. You can now sign your IPAs.

If the icon stays grey or says "Waiting": cancel, delete the icon, check the DNS is active and try another seal.

Sign the IPA

Add the IPA, choose the certificate and sign. When done, install the result.

Asking the sealFrequent questions

Nothing happens when I tap "Install"

It is almost always one of two: you are not in Safari, or the DNS profile is missing. Open the page in Safari and try again.

"Cannot connect to server"

The DNS is missing or the OTA server is saturated. Install the profile, restart and try another certificate.

"Cannot verify the app" when opening it

You skipped trusting it: Settings → General → VPN & Device Management → Trust.

Is the certificate permanent?

No. Company accounts get revoked without warning when Apple closes them. When that happens, change seal and sign again.

What is the profile actually for?

Two things: enabling the encrypted DNS that lets signed apps connect, and putting ZetaSing on your home screen with its icon, like a normal app.

Does it work on iPad?

Yes, with iPadOS 14 or later and always from Safari.
